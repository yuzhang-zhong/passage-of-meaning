# 词渡 · Passage of Meaning — Design System

> 由 `ui-ux-pro-max` 的定向检索结果结合项目技术文档校正。自动检索曾将项目误归类为网络安全平台；本文件以数字人文、公共阅读与档案证据为准。

## 设计方向

- 类型：数字人文 / 公共教育 / 证据阅读 / 时间数据可视化
- 风格：Editorial Grid + E-Ink / Paper + Museum whitespace
- 关键词：安静、当代编辑设计、档案质感、证据优先、有时间厚度
- 标志性动作：低饱和语义河流穿过严格编辑网格，并可退入安静的三栏证据阅读器
- 禁止：网络安全仪表盘、霓虹赛博、AI 蓝紫渐变、玻璃拟态、仿古装饰、彩虹式数据编码

## 色彩

| 角色 | 值 | 用途 |
| --- | --- | --- |
| Paper | `#EFEDE6` | 全局暖纸背景 |
| Paper Deep | `#E5E0D5` | 策展区与阅读器层次 |
| Ink | `#1D211F` | 正文、边界、主控件 |
| Muted Ink | `#6E716B` | 辅助文本；不得用于过小正文 |
| Cinnabar | `#9F3D2D` | 时间节点、批注、焦点与解释状态 |
| Mineral Green | `#315D55` | 证据事实、媒介与第二交互色 |
| Rule | `rgba(29,33,31,.18)` | 编辑网格发丝线 |

含义河流最多同时使用 4–5 个低饱和矿物色。颜色只区分含义；证据等级、争议与置信度必须另外使用字母、线型、纹理或文字。

## 字体

- 展示与引文：`Songti SC`, `STSong`, `Noto Serif CJK SC`, serif
- UI 与正文：`Noto Sans SC`, `Microsoft YaHei`, `PingFang SC`, sans-serif
- 年份与元数据：`Courier New`, monospace
- 不强制联网字体，优先保证简体中文覆盖与首屏稳定
- 正文移动端不小于 16px；仅元数据和图表标注可使用 9–12px，且须有高对比与上下文冗余

## 网格与间距

- 8px 基础节奏；主要间距 16 / 24 / 32 / 48 / 64 / 120
- 首页采用不对称编辑网格；详情页采用 70% 河流 + 30% 证据面板
- 阅读器桌面端为原始扫描 / 校订文本 / 轻量标注三栏，移动端依次堆叠
- 容器保持直角与发丝边界，避免通用圆角卡片；深度主要由留白和网格建立

## 语义河流规则

- 宽度表示每条含义独立计算的活跃程度，不表达总量守恒
- 透明度表示证据/分类稳定性；模糊边缘表示争议；虚线表示数据不足
- 色彩之外必须提供文字标签、选中描边、纹理和可回溯证据
- SVG 系列保持不超过 5 条；移动端可横向探索，但页面本身不得溢出
- 所有图表必须具有文本替代：含义名称、年代、稳定度、代表证据

## 交互与可访问性

- 所有功能可由键盘完成；视觉焦点环使用 2px 朱砂，偏移 4px
- 自定义 SVG 河流支持 Enter / Space；模态阅读器与年代对比支持 Escape 关闭
- 移动端触控目标至少 44px；hover 不是唯一信息入口
- 动画 150–450ms，仅用于页面进入、河流聚焦与阅读模式切换；遵守 `prefers-reduced-motion`
- 使用语义化 `header` / `nav` / `main` / `section` / `article` / `aside`，主页与详情页均有 skip link
- 检查 320、375、414、768、1024、1440px；不允许固定导航遮挡内容

## 状态语言

- 语料事实：矿物绿实点
- 计算结果：蓝灰实点
- 人文解释：朱砂实点
- A / B / C 证据等级始终显示字母与说明，不仅依赖颜色
- 所有演示引文显著标注“待史料核验”，不得呈现为正式历史结论

## 交付检查

- [ ] 无 emoji 代替图标
- [ ] 所有点击目标显示指针与明确 hover/active/focus 状态
- [ ] 正文对比度至少 4.5:1
- [ ] 键盘顺序与视觉顺序一致，模态支持 Escape
- [ ] 尊重减少动态效果偏好
- [ ] 375 / 768 / 1024 / 1440px 布局无页面级横向溢出
- [ ] 图表不只靠颜色传达含义
- [ ] 所有历史判断都能进入证据，演示数据与史实明确区分
